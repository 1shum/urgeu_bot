# 🎓 Умный Telegram-бот для студентов УрГЭУ

Асинхронный Telegram-бот для автоматизации учебного процесса. Помогает студентам отслеживать расписание, получать уведомления о парах и проверять академический рейтинг прямо в мессенджере.

## 🚀 Ключевой функционал
- **Интеграция с порталом УрГЭУ:** Парсинг закрытого образовательного портала с безопасным хранением и дешифрацией паролей.
- **Мониторинг успеваемости:** Динамическая генерация моноширинных таблиц для отображения академического рейтинга и разницы баллов.
- **Умные уведомления (JobQueue):** Ежедневные утренние дайджесты и автоматические алерты за 15 минут до начала конкретной пары.
- **Современный UI/UX:** Навигация через Inline-клавиатуры с динамической подменой медиа-баннеров (без спама новыми сообщениями в чате).

## 🛠 Стек технологий
- **Язык:** Python 3.11+
- **Фреймворк:** `python-telegram-bot` (асинхронная архитектура)
- **База данных:** PostgreSQL (Neon) + `asyncpg`
- **Парсинг:** `BeautifulSoup4`
- **Инфраструктура:** Деплой на Render.com
